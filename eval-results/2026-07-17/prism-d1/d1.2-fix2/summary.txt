THE REGRESSION (shipped unseen at D1.1c, survived 4 checkpoints)
---------------------------------------------------------------
dogfood (run-aspnetcore-microservices) at D1.1c:
  439/339/34 ~1799 tok, STYLE Microservices  ->  439/335/34 ~1536 tok, STYLE CleanArchitecture
  ROUTES block (6 YARP routes) GONE; CROSS-SERVICE "http/via gateway (4)" GONE (== the 4 lost edges)

Root cause: dogfood's gateway project YarpApiGateway (Sdk="Microsoft.NET.Sdk.Web") self-sourced the
`gateway` signal purely by NAME (the Gateway descriptor's Packages list holds the stale id
"Microsoft.ReverseProxy"; dogfood references today's "Yarp.ReverseProxy"). D1.1c added two guards to
DependencyExtractor's self-name loop, and each kills the gateway signal independently:
  1. name-boundary matching: "YarpApiGateway"[4]=='A', not '.', so it no longer matches "Yarp".
  2. runnable-guard (skip IsRunnableService): a Web-SDK project is runnable.
With the signal gone, PopulateGatewayRoutes early-returns, the style detector loses its
"gateway + message bus" evidence, and the whole gateway story disappears.

THE DESIGN CALL
---------------
The guards are RIGHT for framework libraries (a framework core is always a classlib; a consumer host
named after a framework is an exe) and load-bearing for wolverine — but wolverine's descriptor role is
AppEntry, so "scope the guards to FrameworkLibrary" would have broken D1.1c's win. The real outlier is
Gateway: exactly ONE descriptor, and ArchetypeDetector already disambiguates it STRUCTURALLY and better
— peer-service count >=2 => App (ArchetypeDetector.cs:40-43, which states outright "Self-source is NOT
the discriminator ... only the peer count separates them"). The gateway branch runs BEFORE the
framework-library branch, so restoring the signal cannot flip dogfood to Library.

Fix: exempt SurfaceRole.Gateway from BOTH guards.
  - runnable-guard: skipped for Gateway (a gateway host is runnable by nature).
  - name matching: Gateway keeps PREFIX matching (concatenation "YarpApiGateway" IS the gateway naming
    convention, not a consumer smell).
Threaded the descriptor Role through ProjectNameSignalMap so the loop can see it.

RESULT: dogfood byte-identical to the pre-D1.1c baseline — 439/339/34, ~1799 tok, STYLE Microservices
(7 runnable web services with gateway + message bus), ROUTES back, http/via gateway (4) back.
