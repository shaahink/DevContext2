# N3.2 — the repo-file hand-off (STUDIO-MCP §8.3, decision 3)

_2026-08-14 · branch `feat/pre-release-desktop` · commits `6efcef6` (server) + `032c9b8` (app)_

Save writes `.devcontext/packs/<slug>.md` into the analyzed repo, gitignored by default, and hands
back the copyable point-your-agent-here line. Home's "Point your agent here" routes through Studio.

## The mechanism, and why

A **new server RPC** (`SavePackFile`), not a client-side write. The app has no file system it can
reach: the Tauri capabilities scope `fs` to `$LOCALDATA` with no write/mkdir permission, and a repo
lives anywhere, so a browser-only path could never be verified in `dev:web` **and** in the shipped
shell. The server already holds the session's repo root. Anchor = `Snapshot.RootPath` (the root every
`file:line` in the pack is relative to), falling back to `session.RepoRoot`.
