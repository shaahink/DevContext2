## L4.4 delivered

### Proto (additive)
- New messages: ContextPackRequest, ContextCardSpec, ContextPackResponse,
  ContextCardItem, SectionAllocation
- New RPC: GetContextPack — accepts repeated card specs, returns per-card items
  + assembled markdown pack

### C# engine
- ContextPackBuilder.BuildMulti(): traces each unique entry once, picks per-card
  sections by type (CardTypeSections mapping), assembles full markdown pack
- ContextPackBuilder.BuildSections(): extracted section-building logic for reuse
- New types: ContextCardSpec, ContextCardPack, MultiContextPack
- ProtoMapper.ToContextPackResponse(): maps MultiContextPack → proto response

### Server
- DevContextGrpcService.GetContextPack(): creates builder, calls BuildMulti(),
  returns assembled pack via ProtoMapper

### UI (Angular)
- DevContextApi.getContextPack(): typed wrapper over the new gRPC client method
- ContextStudio.loadAllCards(): ONE GetContextPack call replaces N GetContext calls
- ContextStudio.serverPackMarkdown: stored assembled markdown from server
- ContextStudio.buildContext(): Copy/Save uses serverPackMarkdown when available;
  client-side assembly kept as fallback for pre-L4.4 sessions

### Trap A closed
- Before: 9 cards = 9 GetContext RPCs (traffic amplification), all cards get same
  content (no type filtering), client-side assembly (no budget enforcement)
- After: 1 GetContextPack RPC, per-card sections filtered by type, server-assembled
  markdown with budget trimming
