## L4.1 delivered — Flow first-class store on CodeGraph

Three file changes (additive, no existing code modified):

1. **NEW `src/DevContext.Core/Graph/FlowModel.cs`** — Flow, FlowStep, ServiceHop records.
   - `Flow`: Id, Entry, Steps, Touches (NodeId[] — spine-only), Emits (NodeId[]), Hops (ServiceHop[]).
   - `FlowStep`: Node (NodeId), Via (EdgeKind?, null for entry), Tier (Resolution), Provenance (string?).
   - `ServiceHop`: FromService, ToService, Transport, Evidence.

2. **MODIFIED `src/DevContext.Core/Graph/CodeGraph.cs`** — Flow storage:
   - `CodeGraph.Flows` (ImmutableArray<Flow>) — computed flows, one per entry.
   - `CodeGraphBuilder._flows` + `SetFlows()` — mutable accumulator; passed through `Build()`.

3. **MODIFIED `src/DevContext.Core/Graph/GraphBuilder.cs`** — Flow computation:
   - `ComputeFlows()` called between the two `g.Build()` calls (after all edges assembled).
   - Spine-first walk: Sends(0) > Handles(1) > ServiceLink(2) > Raises(3) > Consumes(4) > ReadsWrites(5) > Resolves(6) > Calls(7).
   - Bridges handler-entry member edges from Type nodes (Handle, HandleAsync, Consume, etc.).
   - Stops at framework/system types (Microsoft.*, System.*, DbContext, ILogger, etc.).
   - Touches = ReadsWrites edges FROM spine members only (E5 fix: no EntityRelation reachability).
   - Emits = Raises edges FROM spine members only.
   - ServiceHops = ServiceLink edges encountered on spine (with transport tag + provenance).
