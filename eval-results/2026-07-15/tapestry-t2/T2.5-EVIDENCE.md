# T2.5 — Param-passed dispatch seam (audit A1, the flagship-flow killer)

**Gate:** eShop `POST /api/orders/draft` traces ≥3 hops (entry → handler → domain callee); Sends counts only rise.

## What the audit hypothesised vs. what was actually wrong (R-T4)

The audit A1 root-caused this as `ResolveArgTarget` returning null because the command is a
method parameter (`arg.Type` null) and `BodyFacts` carries no parameters. **Verified against `src/`:
that half was already closed** — `BodyFactExtractor.WalkMember` seeds method/ctor params into the
resolution scope (lines 69–72), so `Send(command)` already resolves `command`'s type. The genuine
blockers were two, and BOTH were needed:

1. **Receiver not recognised.** eShop reaches the sender through an `[AsParameters] OrderServices`
   record: `services.Mediator.Send(command)` (OrdersApi.cs:115). The root identifier is `services`
   (type `OrderServices`), so neither the type-gate nor the variable-name hint fired.
   Fix: `InvocationOp` gains `ReceiverMember` (the receiver's trailing member-access segment, here
   `Mediator`); `MediatRDispatchDetector` recognises a property-accessed MediatR receiver from it,
   while a resolved non-MediatR bare receiver (`IEmailSender sender`) still fails (no false positive).

2. **Global-namespace node-identity mismatch.** eShop's `OrdersApi` has **no namespace**.
   `SyntaxStructureExtractor` keys its `TypeDiscovery.Id` as `global.OrdersApi` (namespace ?? "global"),
   but `BodyFactExtractor.GetTypeFullName` returned bare `OrdersApi` — so the emitted Sends edge sat on
   `OrdersApi::CreateOrderDraftAsync`, orphaned from the entry's handler node
   `global.OrdersApi.CreateOrderDraftAsync`. The trace could never reach it. Fix: `GetTypeFullName`
   uses the same `"global"` fallback. (Discovered by an isolated repro; not called out in the audit.)

## Changes

- `src/DevContext.Core/Graph2/BodyFacts.cs` — `InvocationOp.ReceiverMember` (init property).
- `src/DevContext.Core/Graph2/BodyFactExtractor.cs` — populate `ReceiverMember`; `GetTypeFullName`
  uses the `"global"` fallback (aligns with `SyntaxStructureExtractor.Id`).
- `src/DevContext.Core/Graph2/Seams/MediatRDispatchDetector.cs` — `IsMediatRReceiver` (3-shape
  recognition, precedence type-gate → member-access → bare name-hint).
