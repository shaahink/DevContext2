# T2.8 — Old-graph retirement cleanup + GraphBuilder split (audit §0b)

**Branch:** feat/tapestry-t2 · **Date:** 2026-07-15 · **Behavior-neutral.**

## What shipped

1. **Verified no `kind:` tag parsing remains.** T1.8 deleted `EntryTableProjection.DeriveEntryKind`;
   a fleet grep confirms the only `kind:`-prefixed write is `GraphBuilder.Build`'s
   `g.Tag(entry.Node, …, $"kind:{entry.Kind}")` and **nothing reads it** (the sole other `Tags = [kind…]`
   at the handler-join is an unrelated `MediatRKind` label). The stamping is harmless legacy and was left
   in place — removing it would alter node tags (not counts), which is out of scope for a byte-neutral gate.
2. **Removed the stale `AddSends`/`AddRaises`/`AddDataEdges` comment** in `AddSeamsFromDetectors` — those
   method names were retired long ago and no longer grep to anything.
3. **Split `GraphBuilder.cs` (2484 lines) into partial-class assembler modules by concern:**

   | File | Lines | Concern |
   |---|---|---|
   | `GraphBuilder.cs` | 118 | fields, ctor, entry-builder registry, `Build` orchestration |
   | `GraphBuilder.Flows.cs` | 216 | spine-first flow computation |
   | `GraphBuilder.Entries.cs` | 506 | entry target / score / group-path enrichment |
   | `GraphBuilder.Nodes.cs` | 573 | type/service/entity nodes, handler + pipeline joins, event consumers |
   | `GraphBuilder.Seams.cs` | 797 | DI resolves, call edges, hub-scope, seam detectors, lambda seams |
   | `GraphBuilder.ServiceLinks.cs` | 343 | gRPC/HTTP service links, layer violations, seam-context builders |

   `GraphBuilder` is now `public sealed partial class`. The split was done by a line-range script (a pure
   method move between partial files of one compile-time class **cannot** change behavior if it compiles).
