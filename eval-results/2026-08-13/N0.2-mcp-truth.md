## What changed

**Wire (proto + server, lockstep per the repo rule)**

- New RPC `GetMcpStatus(GetMcpStatusRequest) returns (GetMcpStatusResponse)` — `telemetry_streaming`
  + `observer_count`, both read by the app. Non-mutating server handler.
- `contract-sweep.ps1`: `GATE: PASS — messages 109 · fields 506 · unread 9 (9 allow-listed, 0 NEW)`.
- `docs/product/AGENT-REFERENCE.md` RPC list updated in the same commit.

**App (`mcp-page.ts`, `devcontext-api.ts`)**

- Status is a read. The dot/label report telemetry forwarding — the only thing this server can observe
  — instead of claiming "MCP Endpoint Active". The Start/Stop buttons are left alone: renaming or
  killing them is N4.1's checkpoint, not N0's.
- Host snippets carry the documented full path to the built executable (`mcp-reference.md` §Register)
  with a visible placeholder, and the note tells the user to build it. The false
  "ships with the desktop installer" line is gone. N4.2 replaces the placeholder with the resolved path.
- Copy takes the host from the card. Both copy paths use `core/clipboard.ts` and report failures.
- Feed: total is a computed over the visible rows and is labelled `Shown:`; row time is the wire
  timestamp; dead `session`/`bytes` fields dropped.
- Sessions: `Session` and `Analyzed` are separate columns, `Edges`/`Entries` rendered, and a cached
  analysis is marked `(cached)` with the full instant on hover.
- The three catch-alls (status read, session poll, event stream) each render a visible error.
