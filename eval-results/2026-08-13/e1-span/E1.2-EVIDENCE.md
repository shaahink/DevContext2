### One measured correction to the backlog's account

#12 says the sister sites "are likely to have the same hole; measure each rather than assuming". Measured:

- `TryBindReceiverType`, `TryBindGenericArg` — broken exactly as described.
- `TryBindLocalDeclType` — **NOT broken for a single declaration on its own line**: the line span's
  innermost node IS the `LocalDeclarationStatementSyntax`, so ascending finds it as self. It breaks only
  when two declarations share a line (the span widens to the block). Fixture built for that case.
- `TryBindArgType` — **does not merely miss, it binds the WRONG node**. It already had a
  descendant fallback disambiguated by METHOD NAME, so two same-named calls on one line both bound the
  FIRST call's argument. A dispatched contract read as verified while naming the other command.

## The fix

`BodyOp.Span` (`TextSpan?`) + `BodyFactExtractor` stamping the invocation / declarator / creation /
identifier node it built each op from + one `Relocate` / `RelocateInvocation` pair in
`SemanticLitePopulator` that all five bind sites now share. The line-span walk survives as the fallback
for a span that does not fit the tree it is handed (razor virtual trees are skipped upstream, so no
live consumer takes it today).

`BodyFactsVersion` was NOT bumped, and the previous handoff's instruction to bump it was a false
premise — measured: the constant is read by exactly one consumer, its own pin test, and the BodyFacts
cache is an in-memory per-analysis dictionary keyed by file path (`SharedAnalysisContext`), never
serialised (`SnapshotPersistence.cs:19`). There is no cross-version cache to invalidate.

declare has no in-solution target — skip, never invent. It states the rule `PlainCallDetector`'s own

two-sided build (`lost-edge-diff.ps1`: `src/DevContext.Core` checked out at `795ad1b`, CLI rebuilt,

`System.Collections.Generic.IEnumerable\`1` (×9), `System.Type` (×2), `ConcurrentDictionary\`2` (×3),

`INotificationHandler\`1`, `NotificationHandlerExecutor`, `Pipeline.IRequestPostProcessor\`2`, i.e. the
library's actual dispatch spine, previously invisible.

So the −5 is the graph trading 18 BCL phantoms for 13 real in-solution edges. On both poles the
harness also asserts the end state directly: **head Calls edges whose TYPE target is not a declared
node = 0.**
