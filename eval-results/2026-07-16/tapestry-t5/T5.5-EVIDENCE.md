# T5.5 — Card content honesty (deep-QA findings 40–42, 50)

**Date:** 2026-07-16 · **Branch:** feat/tapestry-t5

## What landed

- **Real previews (finding 40):** the card preview was `ci.title` — a title echo
  ("Flow: /ProductList" told the reader nothing). Now it is the sections' REAL text
  (joined; null when empty so the empty-preview block doesn't render). Rides the T5.3
  `SectionAllocation.content` proto field.
- **Per-card provenance (finding 41):** landed in T5.3 — chips are the card's OWN
  `sourceLocations` union, not the entry's provenance echoed on every card.
- **One unit (finding 42):** the `~NL` line-count badge (shown while estimates stand in
  for server tokens) now displays estimated TOKENS (`~38 tok`), same unit as everything
  else. config/tests stopped being permanent estimates in T5.6 when their specs started
  going to the server (T4.3 sections).
- **The "error badge" (finding 50) was a color-semantics bug, not a missing tooltip:**
  `KIND_COLORS.GrpcService` was `--vibe-danger` — the red kind glyph on
  `DiscountProtoService` read as an error state when nothing was wrong. Fixed the actual
  lie: danger is reserved for errors (gRPC → accent-dim, app-wide via KIND_COLORS), and
  every scope-picker kind glyph now carries a `[title]` naming its kind ("gRPC entry").
  Bonus find, same family: `CARD_TYPE_COLORS.di_wiring` referenced `--vibe-accent-pink`,
  which does not exist in styles.css — the badge silently rendered colorless; di_wiring →
  accent-dim, tests → warn (danger freed).
