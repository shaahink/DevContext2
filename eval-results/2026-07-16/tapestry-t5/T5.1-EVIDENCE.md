## R1 — omitted[] rendered in BudgetPanel

- UI half: `ContextStudio.packOmitted` signal ← `pack.omitted`; `BudgetPanel` renders an
  `Omitted (N)` warn-section (`data-testid="omitted-list"`) listing each server line.
- **Deeper root cause found while driving the gate:** the UI fix alone stayed red because
  `ContextPackBuilder.BuildMulti` BUILT the per-section omission reasons and **discarded**
  them — `var (allSections, _) = BuildSections(...)`. The Studio's `GetContextPack` therefore
  always reported an empty `omitted[]` while silently cutting sections (the single-card
  `Build()` path reported them fine, which is what the audit had seen). Fixed: section
  omissions propagate into the pack response, focus-attributed when the pack spans >1 entry,
  deduped, capped at 12 + `… +N more omissions`.
- Pinned: `ContextPackBuilderTests.Multi_pack_propagates_section_omission_reasons` (15/15
  pack tests green); live drive assertion `E-omitted-list-rendered` PASS at budget 1000
  ("Omitted (3): entities: empty — omitted · config: …"), screenshot `ui/11-context-omitted.png`.

## R4 — error state + retry in CompositionView

- Root cause (audit GAP 5 + one more): the catch block was `for (const c of newCards)
  c.loading = false` — a silent failure AND an in-place mutation of objects already inside the
  `cards` signal, so no change-detection ever fired (zoneless app); the spinners could hang
  visually. Now: failure sets `card.error` immutably via `cards.update`; the card renders a
  danger strip (`data-testid="card-error"`, message + `alert-triangle` icon — newly registered
  in the icon REGISTRY) with a **Retry** button; `onRetry()` re-requests every failed card in
  one batch. Success path explicitly clears `error`.
- The cards themselves show failed state (the plan's "toast only" trap avoided — no toast at all).
- Pinned: 2 specs (error marks cards + DOM, retry recovers content); live drive assertion
  `F-pack-error-retry` PASS — `GetContextPack` aborted via route interception → per-card error
  strips shown (`12-context-error.png`), unroute + Retry click → errors cleared, content loaded
  (`13-context-retry.png`).
