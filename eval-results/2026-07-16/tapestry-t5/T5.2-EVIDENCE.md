## Root cause caught by the live drive (would have shipped a lying panel)

The first live run showed the panel permanently "fresh — identity · 0 files" even after
editing a cited file on disk. `ContextPackBuilder.Build()` handed the focus string RAW to
`Trace()` — it never ran `ResolveFocus` (only `BuildMulti` did). The Studio passes card
entry NODE IDS as the verify focus, so `Trace(nodeId)` returned null, `BuildSections`
early-returned identity-only, and the verifier fingerprinted **zero files**: `found=true`,
always fresh, while the disk drifted underneath. Fixed at the source (T3.1 unified
addressing): `Build()` resolves nodeId/bare-route/title before tracing — every `Build`
caller (GetContext, VerifyContext, MCP get_context) benefits. Pinned:
`Build_resolves_a_node_id_focus_like_a_title` (16/16 pack tests).
