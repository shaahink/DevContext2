# T4.1 — Pack identity header + repo-relative file:line

**Date:** 2026-07-16 · **Branch:** feat/tapestry-t4 (off develop @ 0eca05f)

## What changed

The audit's Q7 pack evidence (empty `# ` title, `file:` without line, absolute paths,
`_Archetype: _`) traced to three defects:

1. **`snapshot.Explanation` is never populated by the pipeline** — `AnalysisIntentResolver`
   produces an Explanation but it is never copied onto `AnalysisSnapshot`, so both the single-pack
   title (`# {Explanation}`) and the Studio header (`_Archetype: {Explanation}_`) rendered empty.
   The pack no longer reads it: the title is `# {repo} — {focus}` (repo = solution name, falling
   back to root folder), and the Studio archetype comes from the Map.
2. **No identity on the snapshot** — `AnalysisSnapshot` gains `AnalyzedAtUtc` + `GitHead`
   (stamped by `DiscoveryPipeline`; `GitHeadReader` extracted from `SnapshotCacheService`'s
   private `ComputeGitHead` so cache keying and pack identity share one reader).
3. **`Location: {path}:{LineNumber}` with `int?` LineNumber** — a null line rendered a dangling
   `path:`. One `Location(file, line)` helper now renders repo-relative `file:line`, or path-only
   when no declaration line is known. Salient-body headings gained `— file:line` so every body
   can be checked against source.

Files: `Core/Pipeline/AnalysisSnapshot.cs`, `Core/Pipeline/DiscoveryPipeline.cs`,
`Core/Analysis/GitHeadReader.cs` (new), `Core/Analysis/SnapshotCacheService.cs`,
`Core/Graph/ContextPackBuilder.cs`, tests `ContextPackBuilderTests.cs` (new, 5),
`AnalyzeFlowTests.cs` (header assert updated).
