# T4.4 — Per-section provenance + tier mix (R10)

**Date:** 2026-07-16 · **Branch:** feat/tapestry-t4

## What changed

Every non-empty pack section now says where it came from and how sure it is:

1. **`SectionProvenance`** accumulates, while each section renders, the repo-relative
   `file:line` set it drew from and the resolution-tier mix — Semantic/Join = **verified**,
   Syntactic = **approx** (the same convention as the trace's `[approx]` markers). Tallied at
   the item level: signatures/bodies/skeleton per rendered step, contracts per declaration
   (verified — the node's own decl), config per key (verified — literal in the syntax tree),
   tests per row (approx — heuristic by design), di_wiring per Resolves edge's own Resolution.
2. **Markdown footer** appended by `tokensAddSection` to every non-empty section:
   `_provenance: 12 source sites · 22 verified · 3 approx_`. Bodies reserve 30 tokens of
   headroom so an exact fill can't tip over budget.
3. **Structured fields** on `SectionAllocation` (`SourceLocations` capped at 20, `Verified`,
   `Approx`) for the Studio's provenance chips (T5.3). Proto exposure rides with T4.5's proto
   batch (one regen for verify_context + section provenance together).
