# T4.6 — Pack assembly correctness (audit C2)

**Date:** 2026-07-16 · **Branch:** feat/tapestry-t4 (same session as T4.1)

## What changed

1. **Contracts ≠ signatures.** `CardTypeSections["contracts"]` was a `["signatures"]` alias — the
   Studio card shipped a verbatim duplicate (the UI even labeled it "signatures: 597 tok").
   New `BuildContracts(trace)`: contract-shaped spine types only — message contracts by role tag
   (command/query/notification/integration-event/domain-event), interfaces and DTOs by their own
   declaration line; entities excluded (they have their own section). Payload = the declaration
   line + repo-relative `file:line`. The section is also in single-focus packs (all intents).
2. **Empty sections omitted AND recorded.** `tokensAddSection` drops whitespace-only content and
   records `"{section}: empty — omitted"`; the outer `if (regs.Length > 0)`-style guards were
   removed so `omitted[]` reporting is uniform. `BuildMulti` drops cards that picked no content
   and records them — no more `"Entities — 0 tok"` headings.
3. **Archetype header filled** — landed with T4.1 (from the Map, not the never-populated
   `snapshot.Explanation`).
4. **HTML comments out of the human copy** — `<!-- context card: … -->` markers removed from
   `AssembledMarkdown` (card boundaries live in the structured `Cards[]`; machine markers belong
   to the JSON export, T5.3).
