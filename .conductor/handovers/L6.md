## What is thin / shortcut / assumed (honest)

| Area | Honesty note |
|------|-------------|
| **L6.4 "Context Studio v2" was not built in this phase** | The L6.4 checkpoint was marked DONE because M8 work (prior phase) had already delivered the full Context Studio. No L6 code was written for it. M8.1a–M8.4 were delivered in the meridian branch; L6 merely confirmed they were ship-ready. |
| **Inspector insights adjacency filter is best-effort, not exact** | `filteredInsights` uses three signal types: `evidenceActions` with `Node:` prefix (precise), `actionTarget` ID match (precise), and a loose `evidence.some(e => e.toLowerCase().includes(title))` fallback (substring, can match "Order" against "OrderService"). Documented as "honest" — the "0 / N" chip clearly tells the user when filtering eliminated insights. The substring fallback can produce false positives on short node names. |
| **MCP page `mcpRunning` signal is initialized to `false`** | On component mount, the actual MCP server state is never queried. If the server was already running MCP (e.g., from a prior session), the page shows "Stopped" incorrectly until the user toggles. The auto-refresh only queries sessions, not MCP status. |
| **`listSessions` poll interval is hardcoded 30s** | No configuration, no backoff on failure, no adaptive polling when MCP is stopped. Acceptable for a dev-facing page. |
| **At-cap toast is identical text across all call sites** | The "Tab limit — close one to open another" message doesn't distinguish between New Analysis, recent-jump, or omnibox-open-recent callers. Low impact. |
| **DPI icon scaling is `-webkit-` prefixed only** | Uses `-webkit-device-pixel-ratio` media queries (line 773–789 of styles.css). Works on Chromium/WebView2 (Tauri), not on Firefox's `resolution` property. Acceptable for a desktop app that ships with WebView2. |
| **No tests cover the confirm-close dialog, Escape handler, or atCap guards** | All tested only by manual verification via the gate battery's visual smoke step. The existing 27 unit tests were not violated (they pass) but no new tests were written for L6.1–L6.6 or the audit fixes. |

## Risks for L7+ and concrete follow-ups

| Risk / follow-up | Suggested action |
|------------------|------------------|
| Inspector insights substring matching can produce false positives | If the "0 / N" chip shows 0 when users expect matches, investigate. The filter is conservative — it marks AS relevant things that might not be (false positive), not vice versa. Only fix if users report noise. |
| MCP page doesn't query MCP running state on mount | Add a `this.client.getMcpStatus()` (or ping the MCP endpoint) in `ngOnInit()` to sync `mcpRunning`. Needs a new RPC or health-check endpoint from the server. |
| `mcpRunning` toggle's `startMcp`/`stopMcp` error paths silence the error if the toggle fails | In `toggleMcp()`, the `.catch()` handler sets `mcpRunning` to the opposite state or shows a toast — but the actual server state may differ. No re-sync after toggle failure. |
| No observer count available in the proto | If showing connected agent count matters, the server needs a `GetMcpStatus` RPC returning `{running, observerCount}`. Until then, the L6.6 "Agents connected. N observer(s)" status line was based on wrong data and was removed. |

## Not a bug — clarification

- **The old `newAnalysis`/`selectRecent`/`openRecent` code canceled the session and closed the tab before opening a new one. The L6 change to `createTab` is intentional — it preserves existing tabs.** The `atCap` guard (F5) was the only gap; now it shows a user-visible toast instead of silently overwriting.
- **The `workbench-page` Ctrl+E → /context handler existed before L6** (M8.1e redirected Ctrl+E from the retired ExportDrawer). L6.5 only added the Shift+E variant. Both now have the `isTypingTarget` guard.

No blocking issue requiring a human decision was found — gates are green and all four
audit bugs are fixed. The MCP page's missing `mcpRunning` initialization and the
inspector's substring-based insight matching are the most notable deferred items.
