## Answer

The chain from the storefront checkout form to the actual database write is:

**Blazor form submit → `BasketState` → HTTP POST to Ordering.API → MediatR idempotency handler → `CreateOrderCommandHandler` → `OrderingContext.SaveEntitiesAsync` → `base.SaveChangesAsync(...)`.**

The final line that writes the order to the database is `_ = await base.SaveChangesAsync(cancellationToken);` inside `OrderingContext.SaveEntitiesAsync` (`src/Ordering.Infrastructure/OrderingContext.cs`, in the `SaveEntitiesAsync` method that begins around line 47; the `SaveChangesAsync` call is ~line 59).
