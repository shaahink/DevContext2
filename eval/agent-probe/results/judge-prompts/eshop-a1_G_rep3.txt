## What this is

**eShop ("AdventureWorks") — a .NET 10 microservices reference e‑commerce application orchestrated by .NET Aspire** (`README.md:1-4`, `README.md:12`). Services communicate over HTTP/gRPC and via a RabbitMQ integration‑event bus, backed by PostgreSQL (with pgvector) and Redis.

## The single runnable entry point

`src/eShop.AppHost` is the Aspire AppHost and the startup project (`src/eShop.AppHost/eShop.AppHost.csproj:1` uses `Aspire.AppHost.Sdk/13.2.0`, `OutputType=Exe`). You run it with `dotnet run --project src/eShop.AppHost/eShop.AppHost.csproj` (`README.md:~70`), or open `eShop.Web.slnf` in VS with AppHost as startup (`eShop.Web.slnf:1-24`). Its own dashboard runs on `https://localhost:19888` (`src/eShop.AppHost/Properties/launchSettings.json:5-8`). Composition is entirely in `src/eShop.AppHost/Program.cs`, ending in `builder.Build().Run()` (`src/eShop.AppHost/Program.cs:103`).

## Processes that start when the solution runs

Containers (`src/eShop.AppHost/Program.cs:7-18`):
- `redis`, `eventbus` (RabbitMQ, persistent lifetime), `postgres` (image `ankane/pgvector`, persistent) hosting databases `catalogdb`, `identitydb`, `orderingdb`, `webhooksdb`.

.NET projects (each its own process):
- **identity-api** — IdentityServer + ASP.NET Identity over `identitydb`, externally exposed, health‑checked (`src/eShop.AppHost/Program.cs:23-26`; `src/Identity.API/Program.cs:1-20`).
- **basket-api** — gRPC‑only service over Redis + RabbitMQ (`src/eShop.AppHost/Program.cs:30-34`; `src/Basket.API/Program.cs:1-14`, `MapGrpcService<BasketService>`).
- **catalog-api** — versioned minimal API + OpenAPI over `catalogdb`/RabbitMQ (`src/eShop.AppHost/Program.cs:36-38`; `src/Catalog.API/Program.cs:1-14`).
- **ordering-api** — versioned minimal API over `orderingdb`; also owns the EF migrations (`src/eShop.AppHost/Program.cs:40-44`, `src/Ordering.API/Program.cs:1-19`).
- **order-processor** — `Microsoft.NET.Sdk.Worker` process running the `GracePeriodManagerService` background service; waits for ordering-api because of migrations (`src/eShop.AppHost/Program.cs:46-49`; `src/OrderProcessor/Program.cs:1-10`; `src/OrderProcessor/Extensions/Extensions.cs:18`; `src/OrderProcessor/Services/GracePeriodManagerService.cs:12`).
- **payment-processor** — event-bus subscriber for `OrderStatusChangedToStockConfirmedIntegrationEvent` (`src/eShop.AppHost/Program.cs:51-52`; `src/PaymentProcessor/Program.cs:1-16`).
- **webhooks-api** — webhook subscription API over `webhooksdb` (`src/eShop.AppHost/Program.cs:54-57`; `src/Webhooks.API/Program.cs:1-20`).
- **mobile-bff** — a YARP reverse proxy resource (no project; routes defined in code) fronting catalog, ordering and identity for mobile clients (`src/eShop.AppHost/Program.cs:60-62`; `src/eShop.AppHost/Extensions.cs:185-249`).
- **webhooksclient** — Blazor Server app that receives webhooks (`src/eShop.AppHost/Program.cs:65-67`; `src/WebhookClient/Program.cs:1-12`).
- **webapp** — the public Blazor Server storefront; calls basket via gRPC (`http://basket-api`) and catalog/ordering via HTTP service discovery (`src/eShop.AppHost/Program.cs:69-77`; `src/WebApp/Program.cs:1-13`; `src/WebApp/Extensions/Extensions.cs:31-38`).

Optional, off by default: OpenAI/Azure OpenAI embeddings+chat, or an Ollama container with OpenWebUI — both gated by `useOpenAI`/`useOllama` booleans set to `false` (`src/eShop.AppHost/Program.cs:80-90`; `src/eShop.AppHost/Extensions.cs:52-183`).

Cross-cutting wiring in AppHost: forwarded-headers env var injected into every project (`src/eShop.AppHost/Extensions.cs:22-47`), self-referencing callback URLs, and identity client callback URLs for all apps (`src/eShop.AppHost/Program.cs:93-101`). `ESHOP_USE_HTTP_ENDPOINTS=1` switches launch profiles to HTTP for Playwright CI (`src/eShop.AppHost/Program.cs:20`, `108-115`).
